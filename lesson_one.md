## ТЕОРИЯ

### 1. `print()` — вывод на экран

**Что это:** функция, которая показывает текст или значения на экране.

**Правильное написание:**
```python
print("Текст в кавычках")
print(42)              # число без кавычек
print("Имя:", "Аня")   # несколько значений через запятую
```

**Параметры:**
- `sep` — разделитель между значениями (по умолчанию пробел)
- `end` — что добавить в конце (по умолчанию перенос строки)

```python
print("A", "B", "C", sep="-")      # A-B-C
print("Привет", end="!\n")         # Привет!
```

---

### 2. Переменные — хранение данных

**Что это:** именованная ячейка памяти, где хранится значение.

**Правильное написание:**
```python
имя_переменной = значение

name = "Аня"           # строка
age = 25               # целое число
height = 1.75          # дробное число
```

**Правила именования:**
- Только буквы, цифры, подчёркивания
- Не начинается с цифры
- Регистр важен: `Age` ≠ `age`
- Стиль: `snake_case` (маленькие буквы с подчёркиваниями)

**Присваивание:**
```python
x = 10        # положили 10 в x
x = 20        # заменили на 20
x = x + 5     # взяли текущее значение, прибавили 5, положили обратно
x += 5        # то же самое, короче
```

---

### 3. `input()` — ввод от пользователя

**Что это:** функция, которая ждёт ввод пользователя и возвращает **всегда строку**.

**Правильное написание:**
```python
text = input("Введите текст: ")      # вернёт строку
number = input("Введите число: ")    # тоже строка!
```

> ⚠️ **Важно:** `input()` всегда возвращает строку. Если нужно число — преобразуй:

```python
age = int(input("Возраст: "))        # преобразуем в целое число
price = float(input("Цена: "))       # преобразуем в дробное число
```

---

### 4. Типы данных

**Что это:** категория значения, определяющая что с ним можно делать.

**Основные типы:**

| Тип | Пример | Описание |
|-----|--------|----------|
| `str` | `"Привет"`, `"123"` | Строка (текст) |
| `int` | `42`, `-7`, `0` | Целое число |
| `float` | `3.14`, `-0.5` | Дробное число |
| `bool` | `True`, `False` | Логический тип |

**Проверка типа:**
```python
print(type(42))        # <class 'int'>
print(type("42"))      # <class 'str'>
print(type(3.14))      # <class 'float'>
```

**Преобразование типов:**
```python
int("12")              # строка → целое: 12
float("3.14")          # строка → дробное: 3.14
str(42)                # число → строка: "42"
int(3.9)               # дробное → целое: 3 (отбрасывает дробную часть)
float(5)               # целое → дробное: 5.0
```

**Ошибки преобразования:**
```python
int("3.5")             # ОШИБКА! Нельзя напрямую строку "3.5" в int
int(float("3.5"))      # Правильно: сначала float, потом int
```

### 5. Арифметические операции

**Что это:** математические действия над числами.

**Основные операции:**

| Операция | Пример | Результат | Описание |
|----------|--------|-----------|----------|
| `+` | `7 + 2` | `9` | сложение |
| `-` | `7 - 2` | `5` | вычитание |
| `*` | `7 * 2` | `14` | умножение |
| `/` | `7 / 2` | `3.5` | деление (всегда `float`) |
| `//` | `7 // 2` | `3` | целочисленное деление |
| `%` | `7 % 2` | `1` | остаток от деления |
| `**` | `2 ** 3` | `8` | возведение в степень |

**Приоритет операций:**
1. Скобки `()`
2. Степень `**`
3. Умножение, деление `* / // %`
4. Сложение, вычитание `+ -`

```python
print(2 + 3 * 4)         # 14 (сначала умножение)
print((2 + 3) * 4)       # 20 (скобки меняют порядок)
```

**Полезные применения `%`:**
```python
n % 2 == 0               # проверка на чётность
n % 10                   # последняя цифра числа
n % 60                   # остаток секунд после полных минут
```

### 6. f-строки — форматированный вывод

**Что это:** способ вставлять переменные и выражения прямо в строку.

**Правильное написание:**
```python
name = "Аня"
age = 25
print(f"Имя: {name}, возраст: {age}")
```

**Форматирование чисел:**
```python
price = 1234.567
print(f"Цена: {price:.2f}")      # 1234.57 (2 знака после запятой)
print(f"Цена: {price:.0f}")      # 1235 (округление до целого)
print(f"Процент: {0.75:.1%}")    # 75.0% (формат процента)
```

**Выражения внутри `{}`:**
```python
a = 5
b = 3
print(f"Сумма: {a + b}")         # Сумма: 8
print(f"Квадрат: {a ** 2}")      # Квадрат: 25
```

### Задача 2. Дележ золота

**Задание:** Ввести количество золота и число игроков. Вывести сколько получит каждый и сколько останется.

**Решение:**
```python
gold = int(input("Золото: "))
players = int(input("Игроки: "))

share = gold // players
remainder = gold % players

print(f"Каждый получит: {share}")
print(f"Остаток: {remainder}")
```

### Задача 3. Перевод секунд

**Задание:** Ввести секунды. Вывести часы, минуты, секунды.

**Решение:**
```python
total = int(input("Секунды: "))

hours = total // 3600
minutes = (total % 3600) // 60
seconds = total % 60

print(f"{hours} ч {minutes} мин {seconds} сек")
```

### Задача 4. Площадь и периметр

**Задание:** Ввести длину и ширину. Вывести площадь и периметр с 2 знаками после запятой.

**Решение:**
```python
length = float(input("Длина: "))
width = float(input("Ширина: "))

area = length * width
perimeter = 2 * (length + width)

print(f"Площадь: {area:.2f}")
print(f"Периметр: {perimeter:.2f}")
```
